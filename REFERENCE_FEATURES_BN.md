# Reference TXT → RIHAM v5 Feature Map

| Reference item | RIHAM v5 implementation |
|---|---|
| Site tagline / identity | Admin-editable Tagline + Store Name |
| 50,000+ customer / 5-star proof | Optional Admin fields; hidden until RIHAM/RIHAM supplies real figures |
| New Arrival / Collection banner | Enable/disable, title, subtitle and image upload in Admin |
| Four USP cards | Four editable title + description cards |
| Customer review images | Up to five uploaded images in a swipeable gallery; customer consent required |
| WhatsApp support | Admin-managed number; floating WhatsApp and contact buttons |
| Product photo, price, sizes, colours | Product cards and product page, up to six images |
| Size chart | Per-product Size Guide text; exact measurements are entered by Admin |
| WhatsApp order handler | Product name, selected size/color, quantity, price and delivery information in message |
| About / Contact | Dedicated pages with editable store copy and contact details |
| Delivery / Return / Privacy | Dedicated policy pages; return terms need client confirmation |
| SEO title/description/keywords, OG | Admin-configurable metadata, product/store structured data |
| GA4 / Meta Pixel | Optional IDs in Admin; no tracking script loads until configured |
| Mobile layout / lazy images / reveal | Mobile-first CSS, lazy-loaded images and gentle reveal transitions |
| Domain / sitemap / robots | Dynamic sitemap.xml and robots.txt routes |

Reference-only facts like Sarrah BD brand name, phone number, Asiya Collection, customer count, rating and review media are not transferred as RIHAM facts.
